以下の要件・設計に対して、実装が完了しているかレビューしてください。判断できなければ必ず確認してください。

対象: $ARGUMENTS

確認観点:

- 導入したコマンドが npm script として実行可能な状態になっていること
- `npm run check`（Format / Lint）と `npm run test` がすべて成功すること
- カバレッジが80%以上を満たしていること（`npx vitest --run --coverage`）
- 設計書に書かれた機能・制約がすべて実装され、テストで検証されていること
- 修正した場合は、デグレードがないように selfcheck を再度実行すること

結果は「完了」「未完了」の一覧で報告してください。
未完了があれば修正プランを提示し、必ず合意を得てから修正してください。合意できない場合はそこで作業を終了してください。
