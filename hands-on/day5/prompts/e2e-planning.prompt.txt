@vibe-order/docs/design/system-design.md を元に、Playwright による E2E テストの実装計画を立ててください。

- 対象は主要なユーザーフロー
  1. 席を選んでメニューから注文する
  2. キッチン画面に新規注文が即時表示される
  3. キッチン画面で状態を「調理中」「提供済」に変更すると、席の画面に即時反映される
  4. 「受付」状態の注文をキャンセルできる。「調理中」以降はキャンセルできない
  5. 売切れのメニューは注文できない
- backend と frontend は Playwright の webServer 設定で起動する
- テストデータは毎回リセット可能にし、テスト間で状態を共有しない
- 失敗時はスクリーンショットと動画を保存する
- CI でも実行できるよう、GitHub Actions のワークフローへの追加計画も含める（reporter は list と html）
